About

This webpage is dedicated to my hobby projects and data visualizations.

I'm inspired by makerspaces, microbes, sumikkogurashi re-ment figurines, lawn ornaments, metal sand casting, and the cats I meet on neighborhood walks.

I've wanted to log the cats I've met on walks for a bit of time now. The project below is an early prototype for the catalog. I could not have made it without significant contributions from AI. I hope to enable features that allow for a more shared archive of the catalog so that it might be a catalyst for meeting more cats .
